# ccmon

Claude Sessions Terminal UI - A TUI application for managing Claude Code sessions.

## Overview

ccmon is a terminal user interface for viewing, managing, and interacting with Claude Code sessions. It provides a structured way to monitor session state, view conversation history, and manage multiple concurrent sessions.
