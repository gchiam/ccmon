Packages

internal/session

Core data types and utilities for session management: Session struct, ProjectGroup, path parsing (ParseCwd), liveness checking (IsAlive), and JSONL path resolution.

internal/watcher

File system monitoring with fsnotify. Detects session creation/removal, tracks JSONL growth, emits SessionsUpdatedMsg and UnreadMsg to the TUI model.

internal/reader

JSONL file polling at 500ms intervals. Parses conversation entries (human, assistant, tool calls), emits ConversationMsg to the model.

internal/model

Bubble Tea model and message types. Handles keyboard input, state management, and event dispatching. Central hub for TUI logic.

internal/ui

Rendering components using lipgloss. Session list, conversation panel, status bar, and Catppuccin Frappé color palette.

cmd/ccmon

Entrypoint. Initializes Bubble Tea program, starts watcher and reader goroutines, manages reader lifecycle on session selection.

internal/session

Types

Exported
type Session struct
Represents a single Claude Code session parsed from ~/.claude/sessions/<pid>.json
PID int — Process ID
SessionID string — Unique session identifier (UUID)
Cwd string — Working directory (absolute path)
StartedAt int64 — Unix timestamp
ProjectName string — Derived from cwd (last path segment)
WorktreeBranch string — Branch name if worktree session, empty otherwise
Alive bool — Result of kill -0 check
JSONLPath string — Resolved path to conversation JSONL file
Exported
type ProjectGroup struct
Groups sessions by project name for UI rendering
Name string — Project name
Sessions []*Session — Sessions in this project
Collapsed bool — UI state: is group collapsed?
Exported
type CwdInfo struct
Result of cwd path parsing
ProjectName string — Project name
WorktreeBranch string — Worktree branch (empty if plain session)

Functions

Exported
func ParseCwd(cwd string) CwdInfo
Parses an absolute cwd path to extract project name and optional worktree branch. Looks for "--claude-worktrees-" delimiter in the basename.
ParseCwd("/Users/alice/myproject") → CwdInfo{ProjectName: "myproject", WorktreeBranch: ""}
ParseCwd("/Users/alice/myproject--claude-worktrees-feat-x") → CwdInfo{ProjectName: "myproject", WorktreeBranch: "feat-x"}
Exported
func IsAlive(pid int) bool
Checks if a process with the given PID is reachable via kill -0 (no signal sent, just check). Returns false for PID ≤ 0.
IsAlive(os.Getpid()) → true
IsAlive(-1) → false
Exported
func FindJSONLPath(cwd, sessionID string) string
Resolves the path to a session's JSONL file. Uses the default ~/.claude/projects/ directory.
FindJSONLPath("/Users/alice/myproject", "session-id-123") → ~/.claude/projects/Users-alice-myproject/session-id-123.jsonl
Exported
func FindJSONLPathIn(baseDir, cwd, sessionID string) string
Testable variant of FindJSONLPath. Accepts explicit projects directory for unit testing.
Exported
func SessionsDir() string
Returns the path to ~/.claude/sessions/

internal/reader

Types

Exported
type Reader struct
Polls a selected session's JSONL file at 500ms intervals. Parses entries and emits ConversationMsg. Fresh instance per session (stateless between sessions).

Functions

Exported
func New(path, sessionID string, program *tea.Program) *Reader
Creates a fresh Reader for the given JSONL path. Program receives ConversationMsg events.
Exported
func (r *Reader) Run(ctx context.Context)
Starts polling. Reads existing JSONL content immediately, then polls at 500ms intervals until ctx is cancelled. Sends ConversationMsg for new entries.
Exported
func ParseLine(line string) (model.ConversationEntry, bool)
Parses a single JSONL line into a ConversationEntry. Returns ok=false for hook events or malformed JSON.
Input types: "human", "assistant" messages with text, tool_use, and tool_result content
Output types: "human", "assistant", "tool_call", "tool_result"

Message Types

All message types implement tea.Msg and are dispatched via program.Send().

Message
SessionsUpdatedMsg
Emitted by watcher when session list changes (create/remove/liveness update)
Sessions []*session.Session
Emitted by: Watcher on CREATE/REMOVE in ~/.claude/sessions/
Frequency: Instant (fsnotify) or ~2s (polling fallback)
Message
UnreadMsg
Emitted by watcher when a non-selected session's JSONL grows
SessionID string
Effect: Sets yellow dot and ✦ indicator on session
Message
ConversationMsg
Emitted by reader when new JSONL entries are parsed
SessionID string
Entries []ConversationEntry
Frequency: ~500ms, only when file grows
Message
WatchErrorMsg
Emitted by watcher if fsnotify setup fails
Err error
Effect: Status bar shows amber warning "File watching unavailable — polling every 2s"

Constants & Paths

Session Directories

~/.claude/sessions/
Directory containing active session files. Each file named <pid>.json contains session metadata.
~/.claude/projects/
Directory containing conversation history. Subdirectories are encoded cwds (cwd with leading '/' stripped and internal '/' replaced with '-'). Each subdir contains <sessionId>.jsonl files.

Polling Intervals

Reader Poll: 500ms
Checks for new JSONL entries while a session is selected
Watcher Fallback: 2s
Checks for session changes when fsnotify is unavailable

UI Constants

Left Panel Width: 24 chars
Session list panel
Minimum Terminal Size: 80x24
Smaller terminals show full-screen warning
Tool Result Truncation: 120 chars
First line only, truncated if longer
