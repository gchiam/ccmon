ccmon

Claude Sessions Terminal UI

A Go TUI for monitoring active Claude Code sessions in real time

Overview

ccmon is a terminal UI application that monitors all active Claude Code sessions on your local machine. It displays conversation history in real time, groups sessions by project, and provides live unread indicators for new activity.

  • View all active Claude Code sessions grouped by project
  • Display scrollable conversation history for selected sessions
  • Instant session updates via file system watching (fsnotify)
  • Unread indicators for sessions with new activity
  • Detect stale processes and show status indicators
  • Worktree-aware session display
